# 使用场景

vein-talk 适合谁、能解决什么问题、和微信 / 钉钉等通用聊天工具有什么区别。

## 一、谁适合用

| 使用者 | 诉求 |
|--------|------|
| 中小企业 / 团队 | 内部沟通协作，数据不出企业 |
| 政企单位 | 私有化部署、内容管控、数据合规 |
| 私域运营者 | 粉丝触达、群发、自动回复 |
| 技术研究与学习者 | 学习评估（测试环境） |

## 二、典型场景

- **企业内部沟通**：组织架构（单位 / 部门）、单聊群聊、音视频通话
- **公告与强触达**：企业号发文后成员强制可见，已读 / 未读名单，一键催办
- **知识沉淀**：知识号文章归档，按号查阅
- **私域运营**：服务号群发（全部粉丝 / 指定用户）、自定义菜单、关键字自动回复
- **测试评估**：单机一键部署，快速搭建测试环境

## 三、与微信 / 钉钉等通用工具的区别

| 维度 | vein-talk | 微信 / 钉钉等 |
|------|-----------|---------------|
| 部署方式 | 私有化部署，数据自主可控 | 平台化 SaaS，数据在厂商侧 |
| 内容管控 | 数据与内容由部署方自主管理、可审计 | 平台统一规则 |
| 公众号触达 | 企业号强触达 + 已读确认 + 催办 | 按平台规则推送 |
| 授权方式 | 按许可证控制用户数 / 在线数 | 订阅收费 |

> vein-talk 定位为通用 IM 软件，提供私有化部署能力；选型请结合实际规模与运维能力，详见 [部署模式](../02-部署安装/01-部署模式.md)。

## 四、规模选型

| 规模 | 建议 |
|------|------|
| 小规模 / 测试 | 单机部署（已适配，一键部署） |
| 中大并发 | 集群部署（规划中） |
| 大规模 / 按需伸缩 | 微服务部署（规划中） |

三种模式对比见 [部署模式](../02-部署安装/01-部署模式.md)；部署步骤见 [单机部署](../02-部署安装/02-单机部署.md)。
