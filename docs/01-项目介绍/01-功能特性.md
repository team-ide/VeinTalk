# 功能特性

> 本文按实际实现整理（2026-10），仅列已提供的功能；标注「规划中」的暂未提供。技术细节见 [技术架构](../04-开发与集成/01-技术架构.md)。

## IM 核心能力

- **单聊 / 群聊**：会话置顶、免打扰、通知方式、清空记录、备注名、群昵称
- **消息类型**：文本（表情 / 链接 / 手机号识别）、图片、语音（按住说话）、视频（缩略图 + 时长 + 应用内播放）、文件、名片、位置、引用回复
- **已读未读**：单聊与群聊回执，群聊成员已读明细（可配置开启或关闭）
- **消息操作**：撤回（10 分钟内）、多选转发、收藏、删除、重发
- **好友体系**：搜索添加、添加验证三选一（允许 / 需要验证 / 不允许）、好友申请、备注
- **群体系**：创建群聊、邀请入群、加群申请、成员管理、管理员、群主转让、解散群
- **多服务器、多账号**：登录与切换，数据按「服务器 × 账号」独立隔离
- **离线消息**：离线拉取、未读计数、在线状态（多设备优先级）
- **消息通知**：通知方式三选一、勿扰模式（自定义时段）、「@我始终提醒」

## 音视频通话

- 语音通话、视频通话
- 单聊（呼叫 / 接听 / 拒接）与群聊（成员选择、多路画面）均支持
- 通话记录以消息气泡呈现（已接通时长 / 已拒接 / 已取消 / 无人接听）
- 会议 / 讨论模式：规划中

## 朋友圈

- 发布（文字 + 最多 9 图）、点赞、评论、删除

## 公众号

- **四类型**：企业号（强制关注、强触达）、部门/团队号、服务号、知识号
- 关注 / 取关、文章发布（草稿 / 定时 / 优先级）、点赞 / 收藏 / 打赏 / 评论
- **已读确认与统计**：已读 / 未读名单、一键催办（企业号公告）
- **自定义菜单 + 关键字自动回复**
- **群发**：全部粉丝 / 指定用户（最多 200 人）/ 单个用户
- 入驻申请与审核（管理后台审批）

## 管理后台

- **数据统计**：在线 / 活跃、增长、消息（按类型 / 会话 / 设备）、登录登出，图表展示
- **用户管理**：正式 / 测试 / 访客用户，批量生成测试用户、启用停用、软删恢复、回收站、登录账号管理
- **公众号管理**：审核（通过 / 驳回）、文章、素材
- **系统设置**：登录注册开关、密码策略、消息与存储、安全锁、测试用户、客户端功能、全局参数、许可证
- **后台管理**：管理员、角色、操作日志、登录日志
- 敏感词、IP 黑名单等页面：规划中（后端接口已具备）

## 开放能力

- OpenAPI：规划中
- **H5 应用**：在聊天中打开 H5 网页应用，可使用获取用户信息、拍照选图、扫码、定位等能力

## 移动端特色

- 多语言（中文 / English）、浅色 / 深色主题、字号三档
- 水印（服务端控制文案，非生产环境强制显示）
- 扫一扫：身份码、服务器、扫码登录
- 应用更新：自动检测、按设备系统与架构智能匹配下载

## 厂商离线推送

- 华为 HMS、小米 MiPush、OPPO、vivo、荣耀 Honor、iOS（APNs）

## 私有化部署与安全

- 服务端以安装包交付，单机一键部署（详见部署文档）
- 数据与文件存储支持多种方案，可按规模选配（详见部署文档）
- **许可证**：按授权控制最大用户数 / 最大在线数 / 群成员上限 / 文件大小等
- **消息内容加密存储**：聊天消息内容加密存储，防止数据库被直接读取时泄露消息内容
- **安全锁**：账号锁 / MAC 地址锁 / IP 地址锁
- 隐私合规：首次启动需同意隐私政策后方可使用
