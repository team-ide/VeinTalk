# 功能特性

> 本文按实际实现整理（2026-10），仅列已提供的功能；标注「规划中」的暂未提供。技术细节见 [技术架构](../04-开发与集成/01-技术架构.md)。

## IM 核心能力

- **单聊 / 群聊**：会话置顶、免打扰、通知方式、清空记录、备注名、群昵称
- **消息类型**：文本（表情 / 链接 / 手机号识别）、图片、语音（按住说话）、视频、文件、名片、位置、引用回复
- **群接龙 / 群投票**：群聊内发起接龙（接龙、查看未接龙成员、结束 / 重开 / 删除）与投票（单选 / 多选、查看未投票成员、结束 / 重开 / 删除），结果实时刷新
- **消息草稿**：未发送的聊天内容自动保存为草稿，会话列表显示草稿标记
- **已读未读**：单聊与群聊回执，群聊成员已读明细（可配置开启或关闭）
- **消息操作**：撤回（10 分钟内）、多选转发、多选删除、收藏、删除、重发、引用跳转
- **好友体系**：搜索添加、添加验证三选一（允许 / 需要验证 / 不允许）、好友申请、备注
- **群体系**：创建群聊（含企业内部群）、邀请入群、加群申请、成员管理、管理员、群主转让、解散群
- **多服务器、多账号**：登录与切换，数据按「服务器 × 账号」独立隔离
- **离线消息**：离线拉取、未读计数、在线状态（多设备优先级）
- **消息通知**：通知方式三选一、勿扰模式（自定义时段）、「@我始终提醒」

## 音视频通话

- 语音通话、视频通话
- 单聊（呼叫 / 接听 / 拒接）与群聊（成员选择、多路画面）均支持
- **讨论模式**：群聊多人自由讨论，多路画面同时展示
- **讲座模式**：主讲人专属画面；听众默认静音，需「举手申请 → 主讲人批准」后发言
- **通话管理**（发起人）：全体静音、关闭成员麦克风 / 摄像头、移出通话、批准发言、通话中拉人
- **忙线提示**：被叫方已在其他通话时，发起方收到忙线提示
- 通话记录以消息卡片呈现（已接通时长 / 已拒接 / 已取消 / 无人接听，可点击回拨）

## 朋友圈

- 发布（文字 + 最多 9 图）、点赞、评论、删除

## 公众号

- **四类型**：企业号（强制关注、强触达）、部门/团队号、服务号、知识号
- 关注 / 取关、文章发布（草稿 / 定时 / 优先级）、点赞 / 收藏 / 打赏 / 评论
- **已读确认与统计**：已读 / 未读名单、一键催办（企业号公告）
- **自定义菜单 + 关键字自动回复**
- **群发**：全部粉丝 / 指定用户（最多 200 人）/ 单个用户
- 入驻申请与审核（管理后台审批）

## 小程序（H5 应用）

- 公众平台创建小程序：名称、分类、图标、网址（H5 网页应用）
- **申请发布与审核**：新版本提交审核，管理后台审批通过后上线；新版本过审前旧版本保持在线
- **可见范围**：公开（所有人可见）或企业内（企业全员可见）
- 移动端**发现页**按分类展示，点击即可打开使用

## 企业组织

- **企业管理**：创建企业（单位），设置企业编码与管理员
- **组织管理**：部门树（创建 / 移动 / 排序 / 删除），成员归属组织
- **组织用户**：添加 / 移除成员、批量导入（CSV / Excel）
- **企业通讯录**：移动端通讯录展示「我的企业」组织树，逐级查看部门与成员
- **企业内部群**：企业成员专属群聊（创建时指定企业 / 部门），会话列表与群资料带标识

## 意见反馈

- 客户端「我的 → 意见反馈」：反馈类型（功能建议 / 使用问题 / 其他）+ 问题说明，可附带截图、视频，一键上传本地日志便于排查
- 管理后台查看、处理与关闭反馈，反馈内容含设备与版本信息

## 管理后台

- **数据统计**：在线 / 活跃、增长、消息（按类型 / 会话 / 设备）、登录登出，图表展示
- **用户管理**：正式 / 测试 / 访客用户，批量生成测试用户、启用停用、软删恢复、回收站、登录账号管理
- **公众号管理**：审核（通过 / 驳回）、文章、素材
- **小程序审核**：查看发布申请与版本记录，通过后上线、驳回（填写原因）
- **企业组织管理**：企业信息、组织机构、组织用户、批量导入
- **意见反馈处理**：查看反馈内容（图片 / 视频 / 日志），标记处理结果
- **系统设置**：登录注册开关、密码策略、消息与存储、安全锁、测试用户、客户端功能、全局参数、许可证
- **后台管理**：管理员、角色、操作日志、登录日志
- **运维**：缓存管理（查看与清理各业务缓存）
- 敏感词、IP 黑名单等页面：规划中（后端接口已具备）

## 开放能力

- OpenAPI：规划中
- **H5 应用**：在聊天中打开 H5 网页应用，可使用获取用户信息、拍照选图、扫码、定位等能力

## 移动端特色

- 多语言（中文 / English）、浅色 / 深色主题、字号三档
- 水印（服务端控制文案，非生产环境强制显示）
- 扫一扫：身份码、服务器、扫码登录
- 应用更新：自动检测、按设备系统与架构智能匹配下载
- **图片浏览**：聊天图片缩略图快速加载，点击全屏查看、左右滑动切换、双击放大
- **聊天增强**：语音消息连续播放与听筒 / 扬声器切换、视频消息内嵌播放、消息草稿

## 厂商离线推送

- 华为 HMS、小米 MiPush、OPPO、vivo、荣耀 Honor、iOS（APNs）

## 私有化部署与安全

- 服务端以安装包交付，单机一键部署（详见部署文档）
- 数据与文件存储支持多种方案，可按规模选配（详见部署文档）
- **许可证**：按授权控制最大用户数 / 最大在线数 / 群成员上限 / 文件大小等
- **消息内容加密存储**：聊天消息内容加密存储，防止数据库被直接读取时泄露消息内容
- **安全锁**：账号锁 / MAC 地址锁 / IP 地址锁
- 隐私合规：首次启动需同意隐私政策后方可使用
