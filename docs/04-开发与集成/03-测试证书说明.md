# 测试证书说明

> 本文面向开发者与运维。

> 证书文件位于仓库 [`certs/`](../../certs/) 目录。

## ⚠️ 安全声明

- 本仓库提供的证书**仅供测试评估使用，禁止用于生产环境**
- 证书私钥（pfx / pvk / keystore 等）已随仓库公开，**视为已放弃其安全性**：任何依赖这些私钥的部署、签名均无安全可言
- 生产环境请自行签发证书并妥善保管私钥

## 三、使用步骤

### 1. Nginx TLS 证书

1. 将证书（crt/pem）与私钥（key）放入部署目录 `nginx/ssl/`
2. 修改 `nginx/conf.d/` 中 https 站点的 `ssl_certificate` 与 `ssl_certificate_key` 指向对应文件
3. 重启 Nginx：`docker compose restart nginx`

### 2. Android 应用签名

```bash
# 查看证书信息
keytool -v -list -keystore veintalk.keystore

# 用证书给 apk 签名（示例）
apksigner sign --ks veintalk.keystore --out signed.apk unsigned.apk
```

或在 Android Studio / 打包工具中配置签名证书。

### 3. iOS 应用签名

1. 在 macOS 上双击 p12 文件导入钥匙串（输入导出密码）
2. 在 Xcode 的 Signing & Capabilities 中选用该证书签名
3. 测试安装需配合测试设备的描述文件（Provisioning Profile）

## 四、自行生成证书（参考）

- **通用测试证书**：makecert / cert2spc / pvk2pfx（Windows，示例见 certs 目录说明文件）
- **Android 签名证书**：

```bash
keytool -genkeypair -v -keystore my-release.keystore \
  -alias my-key -keyalg RSA -keysize 2048 -validity 10000
```

- **生产 TLS 证书**：建议使用 Let's Encrypt 或正规 CA 签发的证书

> 再次强调：本目录公开的证书仅限测试，切勿在生产环境使用。
