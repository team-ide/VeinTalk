# 更新路线图

> 依据源码功能盘点（2026-10，工程 docs/功能盘点/）与当前发布状态整理；「已完成」项详见 [功能特性](../01-项目介绍/01-功能特性.md) 与各端使用说明。

## 已完成功能（当前版本）

- **IM 核心**：单聊 / 群聊、消息类型（文本 / 图片 / 语音 / 视频 / 文件 / 名片 / 位置 / 引用等）、已读未读（群聊明细可配置）、撤回、多选转发、收藏、好友体系、群体系、多服务器多账号、离线拉取、消息通知与免打扰
- **音视频通话**：语音 / 视频、单聊 / 群聊
- **朋友圈**：发布（文字 + 图片）、点赞、评论、删除
- **公众号**：四类型（企业号 / 部门号 / 服务号 / 知识号）、关注 / 取关、文章发布、已读确认与催办、自定义菜单 + 关键字自动回复、群发、素材、入驻审核
- **管理后台**：用户 / 群 / 公众号管理、数据统计、系统设置、许可证
- **公众平台**：扫码登录、素材管理、文章发布、群发、已读统计
- **移动端特色**：多语言、主题、字号、水印、扫一扫、应用自动更新
- **厂商离线推送**：华为 HMS / 小米 / OPPO / vivo / 荣耀 / iOS（APNs）
- **安全**：私有化部署、许可证、安全锁、隐私政策门禁、**消息内容加密存储（2026-10 新增）**

## 未完成 / 规划中

> 按源码盘点整理，仅列实际未提供的能力。

| 方向 | 内容 |
|------|------|
| 音视频 | 会议 / 讨论（meeting / live）模式入口、来电铃声与震动、扬声器切换、独立通话记录页、群成员中途加入实时刷新 |
| 群 | 群公告、群二维码、主动加群申请界面 |
| 消息 | 服务端消息撤回（MessageRecall）、多选批量删除 |

| 收藏 | 类型筛选、转发收藏项 |

| 开放能力 | OpenAPI 接入 |
| 部署 | 集群部署、微服务部署 |
