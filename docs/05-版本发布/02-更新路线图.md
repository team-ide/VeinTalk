# 更新路线图

> 依据源码功能盘点（2026-10，工程 docs/功能盘点/）与当前发布状态整理；「已完成」项详见 [功能特性](../01-项目介绍/01-功能特性.md) 与各端使用说明。

## 已完成功能（当前版本）

- **IM 核心**：单聊 / 群聊、消息类型（文本 / 图片 / 语音 / 视频 / 文件 / 名片 / 位置 / 引用等）、已读未读（群聊明细可配置）、撤回、多选转发、多选删除、收藏、消息草稿、引用跳转、好友体系、群体系、多服务器多账号、离线拉取、消息通知与免打扰
- **群接龙 / 群投票**：群聊发起接龙与投票（单选 / 多选）、未参与成员查看、结束 / 重开 / 删除、消息卡片实时刷新
- **音视频通话**：语音 / 视频、单聊 / 群聊；讨论模式（多路画面）与讲座模式（举手发言）；发起人管理面板（全体静音 / 关闭成员音视频 / 移出 / 批准发言 / 通话中拉人）；忙线提示；通话记录卡片与回拨
- **朋友圈**：发布（文字 + 图片）、点赞、评论、删除
- **公众号**：四类型（企业号 / 部门号 / 服务号 / 知识号）、关注 / 取关、文章发布、已读确认与催办、自定义菜单 + 关键字自动回复、群发、素材、入驻审核
- **小程序（H5 应用）**：公众平台创建与申请发布、版本审核、发现页分类展示、公开 / 企业内可见范围
- **企业组织**：企业管理、组织机构（部门树）、组织用户与批量导入、移动端企业通讯录、企业内部群
- **意见反馈**：客户端提交（图片 / 视频 / 日志）、管理后台查看处理
- **管理后台**：用户 / 群 / 公众号管理、小程序审核、企业组织管理、意见反馈、数据统计、系统设置、许可证、运维缓存管理
- **公众平台**：扫码登录、素材管理、文章发布、群发、已读统计、自定义菜单、小程序管理
- **移动端特色**：多语言、主题、字号、水印、扫一扫、应用自动更新、图片缩略图与多图浏览、语音连播、视频内嵌播放
- **厂商离线推送**：华为 HMS / 小米 / OPPO / vivo / 荣耀 / iOS（APNs）
- **安全**：私有化部署、许可证、安全锁、隐私政策门禁、**消息内容加密存储（2026-10 新增）**
