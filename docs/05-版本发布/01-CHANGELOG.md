### 🚀 新增功能

- 消息内容加密存储（安全增强）：消息内容加密存储，防止数据库被直接读取时泄露消息明文
- **许可证强制校验**：按授权控制最大用户数 / 最大在线数（超限拦截新增）；许可证到期后服务自动进入只读模式（可查看，禁止新增数据），移动端 / 管理后台 / 公众平台同步提示
- **公告管理 + 消息群发**：管理后台发布公告（正文 / 图片附件，全员 / 企业 / 部门 / 指定用户范围，置顶 / 草稿 / 撤回，已读未读统计）；移动端「我的 → 公告」列表 / 详情 / 未读提醒；消息群发（文本 / 图片 / 语音 / 视频 / 文件，按全员 / 企业 / 部门 / 指定用户 / 设备类型定向）以「系统通知」会话送达，含群发记录与发送明细
- **账号安全与登录设置**（移动端）：多设备管理（登录设备列表 / 在线状态 / 踢出设备）、登录记录（成功 / 失败筛选）、修改密码（修改后其他设备退出登录）、设备管理（解除绑定）、账号注销（申请 → 15 天冷静期 → 生效，期间登录自动撤销）
- **公众号关键字自动回复（独立规则）**：公众平台「自动回复」配置关键字规则（完全 / 包含匹配，最多 200 条，按顺序匹配），回复文本 / 图片 / 语音 / 视频 / 图文；规则优先于菜单关键字
- **图文素材与图文消息**：素材库新增图文类型（1~8 篇已发布文章组合，支持排序）；群发与自动回复的图文为**一条消息携带多篇文章**（封面 + 文章列表），移动端多图文卡片展示
- **数据库方言机制**：服务端接入数据库方言注册机制（当前适配 SQLite / MySQL），支持扩展 PostgreSQL、Oracle、达梦、金仓、openGauss、GBase、瀚高、神通、DB2 等国产数据库
- **音视频通话改造**：群聊支持讨论模式（多人多路画面）与讲座模式（主讲人画面、举手申请发言）；发起人管理面板（全体静音 / 关闭成员麦克风摄像头 / 移出通话 / 批准发言 / 通话中拉人）；忙线提示；通话状态由服务端维护，通话记录以消息卡片呈现、可回拨
- **群接龙 / 群投票**：群聊内发起接龙与投票（单选 / 多选），消息卡片实时刷新，发起人可查看未参与成员、结束 / 重开 / 删除
- **企业组织**：企业管理（企业 / 编码 / 管理员）、组织机构（部门树创建 / 移动 / 排序 / 删除）、组织用户（添加 / 移出 / 批量导入 CSV·Excel）、移动端企业通讯录（组织树逐级查看）
- **企业内部群**：企业成员专属群聊（指定企业 / 部门），会话列表与群资料带标识，非企业成员不可加入
- **小程序（H5 应用）**：公众平台创建 / 编辑 / 申请发布与版本记录；管理后台审核（通过上线 / 拒绝）；移动端发现页按分类展示，支持公开与企业内两种可见范围
- **意见反馈**：客户端提交反馈（类型 + 说明 + 截图 / 视频 + 一键上传日志），管理后台查看与处理
- **聊天增强**：消息草稿（会话列表草稿标记）、图片全屏多图切换与双击放大、视频内嵌播放、语音自动连播与听筒 / 扬声器切换、多选批量删除、引用跳转
- **图片缩略图**：上传自动生成缩略图，列表与聊天中缩略图优先加载、失败回退原图
- **运维缓存管理**：管理后台查看与清理各业务缓存（本地 / Redis 两种模式）
- **数据备份 / 数据还原**：管理后台按需备份业务数据（手动 / 定时自动，指定库表范围），备份自动打包并支持同步到远程服务器；支持按备份记录或服务器路径还原（重建 / 清空两种模式），备份与还原记录留痕
- **运维工具（Web 控制台）**：随服务端部署的运维控制台（`/vein-tool/`）——模拟测试（模拟真实客户端登录、长连接、好友互加、建群、消息收发全流程，校验消息送达与时延，报告含 TPS 与耗时分档，入库可查）；接口压测（登录 / 发消息 / 注册 / 自定义接口四类，按统计窗口展示实时指标，同步采集各节点 CPU / 内存 / 磁盘 / 网络对照）；日志搜索（按服务 / 文件 / 级别 / 时间范围检索，支持正则、上下文行、快捷搜索与下载）；日志分析（任务式统计：级别分布 / 错误 Top / 慢请求 Top / 时间分布，任务可停止，结果可导出为离线分析库）；解压管理
- **服务日志增强**：服务端日志逐行带服务名与进程号前缀，多服务部署时便于按服务定位与区分进程重启
- **资源监控**：各服务节点周期采集 CPU / 内存 / 磁盘 / 网络与进程信息，压测时按窗口对照展示
