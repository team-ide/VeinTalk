## 校验说明

- 每个发布物在 Releases 说明中附带 SHA-256 校验值；
- 下载后请校验完整性：
  - Linux / macOS：`sha256sum 文件名`
  - Windows：`certutil -hashfile 文件名 SHA256`

## 维护者上传说明

1. 按命名规范打包发布物；
2. 分别在 GitHub、Gitee 创建同版本 Release，上传附件；
3. 在 Release 说明中附 SHA-256 校验值与更新内容；
4. 回到本文档补全下载链接。
