# 部署模式（面向运维）

vein-talk 支持三种部署模式，当前仅**单机部署**已适配；集群与微服务部署为规划中。

## 三种模式对比

| 维度 | 单机部署 | 集群部署 | 微服务部署 |
|------|----------|----------|------------|
| 服务形态 | 单个聚合服务（server-all） | 单个聚合服务（server-all） | 多个独立服务 |
| 进程 | 单进程 | 多进程 | 多进程 |
| 接入网关 | 单接入网关 | 多接入网关 | 多接入网关 |
| 注册中心 | — | ZK | ZK |
| 配置中心 | — | etcd | etcd |
| 缓存 | 内存 或 Redis | Redis | Redis |
| 队列 | 内存 或 Kafka | Kafka | Kafka |
| 数据库 | SQLite 或 MySQL | MySQL | MySQL |
| 文件存储 | MinIO | MinIO | MinIO |
| 入口 | Nginx | Nginx | Nginx |
| 适用规模 | 小规模 / 测试 | 中大并发 | 大规模 / 按需伸缩 |
| 状态 | ✅ 已适配 | ⏳ 规划中 | ⏳ 规划中 |

## 选型建议

- **单机部署**：起步默认选择。docker-compose 一键启动，MySQL/SQLite、Redis 均可选，适合测试、试用与中小规模（百人级团队）
- **集群部署**：单机遇到瓶颈后的平滑扩展（多进程 + 多网关 + 共享 Redis/Kafka），适合中大并发
- **微服务部署**：需要按服务独立伸缩或大规模部署时选择，运维复杂度最高

## 交付形态

服务端以 **Docker 镜像 + docker-compose.yml** 交付：

- 服务端镜像离线包：`vein-talk-aio:<版本>-<架构>.tar.gz`（docker load 导入）
- docker-compose.yml 与配置模板：随版本发布到 GitHub / Gitee Releases（见 [下载中心](../05-版本发布/00-下载中心.md)）
