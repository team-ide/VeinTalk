# 移动端使用说明

移动端客户端支持 Android 与 iOS。初次使用建议先看 [快速体验](00-快速体验.md)。

## 一、安装

- **Android**：在 [下载中心](../05-版本发布/00-下载中心.md) 下载对应架构的 apk：
  - [vein-talk-v1.0.10-arm64-v8a.apk](https://gitee.com/teamide/VeinTalk/releases/download/v1.0.10/vein-talk-v1.0.10-arm64-v8a.apk)（64 位设备，绝大多数手机）
  - [vein-talk-v1.0.10-armeabi-v7a.apk](https://gitee.com/teamide/VeinTalk/releases/download/v1.0.10/vein-talk-v1.0.10-armeabi-v7a.apk)（32 位设备）
  - 下载后点击安装即可；若系统提示"未知来源"，请允许本次安装
- **iOS**：下载 ipa 后需签名安装（企业证书或 TestFlight），见 [测试证书说明](../04-开发与集成/03-测试证书说明.md)
- **Web 版**：部署方门户提供 Web 客户端入口（`/vein-mobile/`），浏览器直接使用

## 二、首次启动

1. 首次启动会弹出**隐私政策**，同意后才可使用（拒绝将退出应用）
2. 应用会在你同意隐私政策后才初始化推送等第三方 SDK、申请通知权限

## 三、服务器配置

1. 启动后进入服务器配置页：
   - 选择预设服务器列表中的服务器
   - 或「自定义添加」：输入服务器地址（部署方通常提供形如 `https://vein-talk.com` 的域名地址，应用自动探测；内网测试可用 `http://<IP>:30110/vein-gateway/`）
2. 推荐**扫码添加服务器**：扫描部署方**门户首页的服务器二维码**，自动完成服务器地址配置
3. 可保存多个服务器，随时切换

## 四、注册与登录

- **账号密码登录**：输入账号、密码登录
- **注册**：登录页点「注册」，按页面提示填写（注册项由服务器配置：账号/手机号/邮箱等；手机号、邮箱项需验证码）
- **测试用户快捷登录**：服务器开启测试用户时，登录页提供免密快捷登录入口（选择测试账号一键登录）
- **自动登录**：登录成功后本机记住登录状态，下次启动自动进入
- **多端登录**：同一账号在其他设备登录时，本机会弹出确认（本机重登/他机重登）

## 五、多账号与切换

- 支持同一服务器多个账号、多个服务器分别登录
- 顶部用户名栏可展开：切换账号、切换服务器
- 每个「服务器 × 账号」的数据相互独立（本地数据库隔离），删除登录用户会清空其本机数据

## 六、通讯录与好友

- 通讯录页：新的朋友、群聊、公众号、好友列表（按名称分组）
- **添加好友**：点右上角 `+` → 添加好友，搜索用户名/账号，发送验证消息；对方同意后成为好友
- **申请处理**：新的朋友中处理好友申请、群申请（接受/拒绝）
- **好友详情**：长按或点击好友头像查看详情，可修改备注、删除好友、加入黑名单
- **添加方式设置**：我的 → 隐私设置，可设置「允许 / 需要验证 / 不允许」添加好友、邀请入群

## 七、会话与消息

- **会话列表**：未读角标、最后消息预览、置顶、免打扰标记；长按会话可隐藏
- **会话设置**：进入聊天页右上角，可设置：
  - 置顶、免打扰、消息通知方式（详情/来源/隐藏）
  - 清空聊天记录、查找聊天记录
  - 单聊：备注名、删除好友；群聊：群名称/群头像/我的群昵称/成员管理
- **发送消息**：
  - 文本：直接输入发送
  - 语音：输入框左侧切换到语音，按住说话（上滑取消，最长 60 秒）
  - 图片/视频：点 `+` → 「图片/视频」多选发送（自动识别类型）；「拍摄」拍照发送
  - 文件、位置、名片：点 `+` 对应入口
  - 表情：输入框右侧表情按钮（微信表情 / Emoji）
- **消息操作**：长按消息可复制、转发、收藏、撤回（10 分钟内）、删除、引用、多选
- **已读回执**：单聊显示已读/未读；群聊显示已读人数，点开可看成员明细（由服务器开关控制）
- **搜索**：顶部搜索可搜联系人/群聊/公众号/聊天记录，点击聊天记录可定位到消息

## 八、音视频通话

- **发起**：聊天页 `+` → 语音通话/视频通话
  - 单聊：确认后呼叫对方
  - 群聊：先选择成员（至少 2 人），发起即进入通话
- **接听**：来电全屏弹出，接听/拒接
- **通话中**：静音、摄像头开关、前后摄像头切换、悬浮小窗
- 通话记录以聊天消息呈现（已接通时长/已拒接/已取消）

## 九、朋友圈

- 入口：发现 → 朋友圈
- 发布：文字 + 最多 9 张图片
- 互动：点赞、评论（详情页可删除自己的评论）

## 十、公众号

- **发现与关注**：通讯录 → 公众号，或发现页；按类型筛选（企业号/部门号/服务号/知识号）；企业号与服务号为强制关注，不可取关
- **查看文章**：公众号详情 → 文章列表 → 文章详情（点赞/收藏/打赏/评论）
- **已读确认**：企业号带"需确认"的文章打开后有「确认已读」入口
- **写文章**：公众号运营者可在详情页点「写文章」：标题/正文、优先级、已读确认、定时发布、存草稿
- **运营者面板**：已读/未读统计、一键催办、撤回/删除文章
- **申请入驻**：发现 → 申请入驻（可选部门/团队号、知识号），提交后等待管理后台审核
- **公众号会话**：关注后公众号出现在会话列表，支持自定义菜单（跳转网页/发送关键字）

## 十一、我的与设置

- **基础资料**：头像、昵称、性别、个性签名
- **身份码**：我的身份码为个人二维码，可保存分享，对方扫码加好友
- **界面与语言**：语言（简体中文/English）、主题（浅色/深色/跟随系统）、字号（小/标准/大）、回车发送开关
- **隐私设置**：允许私信、添加好友验证、邀请入群验证
- **通知设置**：新消息通知、显示方式（标题和内容/仅标题/全部隐藏）、提示音、勿扰模式（自定义时段）、@我始终提醒
- **黑名单**：查看与解除
- **检查更新**：检测新版本（服务器发布后客户端可自动更新）

> 注：登录设置（多设备管理、登录记录）与账号安全（修改密码、设备管理、账号注销）页面目前开发中。

## 十二、常见问题

| 现象 | 处理 |
|------|------|
| 登录不上 | 检查服务器地址与网络；确认账号密码正确 |
| 收不到新消息 | 确认通知权限已开；勿扰模式是否开启 |
| 收不到离线推送 | 服务器需配置对应厂商推送；部分机型需允许后台运行/自启动 |
| 无法发起通话 | 检查服务器 LiveKit 是否部署；网络需可达 7881/7882 端口 |
| 消息发不出去 | 检查是否断线（顶部状态灯），断线会自动重连，或重启应用 |
