# 运维工具使用说明

> 本文面向运维与测试人员。

运维工具是随服务端部署的 Web 控制台，提供服务运维与性能测试能力：模拟测试、接口压测、日志搜索、日志分析、解压管理等。所有任务均在服务端执行，页面仅提交配置与查看结果，关闭页面不影响任务运行。

## 一、访问与登录

- 访问地址：部署方提供的运维工具地址，通常为 `http(s)://<域名>/vein-tool/`（如 `https://vein-talk.com/vein-tool/`）
- 无需单独登录，通过部署环境的访问控制保护（建议仅对部署方内部网络开放）

## 二、模拟测试

模拟真实客户端的完整使用流程（登录、长连接、好友、群聊、消息收发），用于验证服务端功能是否正常、消息链路是否通畅。

- **测试流程**（分阶段顺序执行，页面实时显示各阶段进度）：
  1. 登录：模拟用户登录接入服务器
  2. 在线保持：维持长连接与心跳
  3. 离线重连：主动断开连接后重连，验证重连与消息补偿
  4. 好友互加：随机用户两两互加好友（申请 → 同意）
  5. 建群：随机成员创建群聊
  6. 消息收发：单聊与群聊发送消息，校验对方是否真实收到并统计送达耗时
  7. 登出
- **测试账号**：
  - 自动生成：测试时自动批量生成测试账号，测试结束自动清理
  - 使用已有账号：指定账号前缀，复用已有的测试用户（密码为空时使用系统默认密码）
- **测试报告**：成功数、失败数、TPS、平均 / 最小 / 最大耗时、耗时分布（≤100ms / ≤200ms / ≤500ms / ≤1000ms / >1000ms 各档数量与占比）；报告入库保存，可随时查看历史记录
- 模拟测试与接口压测共用执行通道，同一时间只允许一个任务运行；进行中的任务可随时停止

## 三、接口压测

对服务端接口发起规模化请求，评估并发性能；压测过程同步采集各服务器节点资源，便于对照分析瓶颈。

- **压测类型**：
  - 登录：循环登录 / 登出
  - 发送消息：全部用户登录后建群 / 单聊，循环发送消息（可选送达校验）
  - 注册：批量注册新用户（结束后自动清理）
  - 自定义接口：指定接口路径与参数（支持 `{index}`、`{userId}`、`{account}` 等占位符）
- **实时指标**：总请求、成功 / 失败、TPS、平均 / 最小 / 最大耗时、耗时分档分布；支持按统计窗口（如每 5 秒）展示窗口内指标与累计指标
- **资源对照**：压测期间按窗口采集各服务器节点的 CPU / 内存 / 磁盘 / 网络指标，与请求指标对照展示，多节点时分别标注
- **报告入库**：与模拟测试同格式的报告，含测试类型、指标与耗时分布，历史可查

## 四、日志搜索

搜索各服务日志文件，快速定位问题。

- 服务与文件：选择服务（自动列出该服务的日志文件，含轮转文件与压缩轮转），可多选文件
- 搜索条件：关键字（文本或正则）、日志级别（DEBUG / INFO / WARN / ERROR）、起止时间范围、匹配行前后各 N 行上下文
- **快捷搜索**：一键检索常见问题——错误、panic、警告、异常堆栈、慢请求（超过阈值耗时的请求）、超时、SQL、链路追踪编号（trackId）
- 结果展示：匹配行列表（时间、级别、位置、内容），下载当前结果（单文件或压缩包）

## 五、日志分析

按任务方式对日志做统计分析，适合对一段时间的日志做整体体检。

- 新建任务：选择服务与文件、时间范围，启动后后台执行，页面轮询显示进度（实时匹配行数）
- 分析结果：
  - 级别统计：各级别日志数量
  - 错误 Top：错误消息归一化聚合，Top 20
  - 慢请求 Top：超过阈值的慢请求列表，Top 100
  - 时间分布：按秒 / 时间桶的日志量柱状图
  - 明细列表：匹配行分页查看
- 任务管理：任务列表（状态：执行中 / 完成 / 失败 / 已停止）、执行中的任务可停止、同时最多 2 个任务执行、历史任务可删除
- **导出分析库**：任务结果可导出为独立的分析库文件，离线查看（自包含，含任务信息与全部明细）

## 六、解压管理

- 提交服务器上的压缩包路径（如上传的备份包），服务端解压并生成记录：格式、源大小、解压路径 / 目录、解压大小、状态（成功 / 失败原因）、最后使用时间；不再使用的解压记录可删除

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 访问运维工具提示找不到页面 | 确认地址与部署方提供的一致，路径为 `/vein-tool/` |
| 模拟测试 / 压测一直不结束 | 可在页面点击停止；任务由服务端执行，停止后稍等状态更新 |
| 压测无资源数据 | 确认压测统计窗口未关闭（窗口秒数为 0 时不采集资源） |
| 日志搜索找不到服务或文件 | 确认服务已启动并产生日志；可搜索的服务与文件由部署配置决定 |
| 模拟测试报告全部失败 | 查看失败原因列：多为登录失败（账号 / 密码配置），或服务器未开启测试用户功能 |
