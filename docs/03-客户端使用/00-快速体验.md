# 快速体验

5 分钟上手：下载客户端 → 连接体验服务器 → 开始使用。

## 一、下载安装

1. 下载移动端安装包（Gitee Releases，详见 [下载中心](../05-版本发布/00-下载中心.md)）：
   - **Android 64 位**（绝大多数手机）：[vein-talk-v1.0.10-arm64-v8a.apk](https://gitee.com/teamide/VeinTalk/releases/download/v1.0.10/vein-talk-v1.0.10-arm64-v8a.apk)
   - **Android 32 位**：[vein-talk-v1.0.10-armeabi-v7a.apk](https://gitee.com/teamide/VeinTalk/releases/download/v1.0.10/vein-talk-v1.0.10-armeabi-v7a.apk)
   - 下载后点击安装；若系统提示"未知来源"，请允许本次安装
   - **iOS**：ipa 需签名安装，见 [测试证书说明](../04-开发与集成/03-测试证书说明.md)
2. 首次启动阅读并同意隐私政策

## 二、连接体验服务器

> **体验服务器**
>
> - 服务器地址：`https://coos.top`（添加服务器时直接输入即可）
> - 二维码图片：待补充
>
> ⚠️ 体验服务器仅供测试评估，**数据会定期清理**，请勿存放重要数据。

1. 打开应用，在服务器配置页「自定义添加」输入上方地址（或直接扫描二维码）
2. 选择该服务器进入登录页

## 三、注册或登录

- 体验服务器开启测试用户时，可直接用**测试账号快捷登录**（免密一键登录）
- 或点「注册」创建自己的账号后登录

## 四、5 分钟核心操作

1. **加好友**：通讯录 → 搜索账号 → 添加（按服务器设置，可能需要对方验证）
2. **建群**：发起群聊 → 选择成员 → 创建
3. **发消息**：打开会话，发送文本、图片、语音、文件等消息
4. **群接龙 / 投票**：群聊 `+` → 接龙 / 投票，和群友互动
5. **音视频通话**：会话右上角发起语音 / 视频通话（群聊可选讨论 / 讲座模式）
6. **看朋友圈**：发现 → 朋友圈，可发布、点赞、评论
